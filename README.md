# 🧠 NeuroKids — El Cerebro que Aprende Jugando

Blog educativo super moderno sobre **Neurociencia, Memoria y Atención Infantil (4-5 años)**.
Hecho con HTML + CSS + JS puro. Sin frameworks. Brutal, responsive, con modo oscuro, juegos y quiz.

## ✨ Incluye lo pedido
- ¿Qué es la neurociencia educativa?
- Cerebro y aprendizaje infantil (tabs interactivas)
- Atención 4-5 años + juego "Encuentra el diferente"
- Memoria y aprendizaje + minijuego de parejas
- Emociones, juego y motivación + 2 videos
- **4 actividades didácticas** (2 atención + 2 memoria) con nombre, objetivo, materiales, procedimiento, beneficio y ejemplo de aula
- Ejemplos de aplicación en aula de Educación Inicial
- Fuentes bibliográficas
- Guion de 1 min para exposición + quiz de 5 preguntas
